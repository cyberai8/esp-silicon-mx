# 中文音素 → 视素映射说明（服务端）

**读者**：服务端 / TTS 对接  
**目的**：把拼音/音素落到 Viseme ID；明确**哪些音不单独做素材**。  
**配套设计交付**：**11 张**口型图（ID 0～10），见《中文音素口型_设计制作说明》。  
**版本**：v1.2（修正：ü ≠ er；ü ≠ üe，üe/üan 按滑音处理）

---

## 1. 原则（先读）

1. **不是每个音素一张图。** 多个音素共用同一 Viseme。  
2. **不单独做素材** ≠ 服务端不输出该音素；仍可有时间戳，但 `viseme_id` 指向已有 ID。  
3. 声母若「嘴形弱」，时长很短，可输出该 ID，或直接并进后面韵母（由实现选择）。  
4. 设备端只认识 **ID 0～10**。  
5. **ü、üe、er 三者不要混为一谈**（见 §2）。

### 为何 ü ≠ er ≠ üe

| | ü | üe | er |
|:---|:---|:---|:---|
| 本质 | 单元音撮口 | **滑音**：先撮口再展向 e | 儿化卷舌 |
| 唇形 | 撮圆收紧、开口小 | 前半像 ü，后半更开、更接近 e | 略开、唇自然，不撮口 |
| 例字 | 女、绿、律 | 月、略、决 | 二、而、儿、耳 |
| 服务端 | 整段 **ID 9** | **推荐 9→5**（不要整段只用 9） | 整段 **ID 10** |
| 是否新做图 | ✅ ID9 | ❌ 不新做，复用 9+5 | ✅ ID10 |

**禁止：**

- 把 **er** 映射成 9  
- 把 **üe** 整段等同于纯 **ü**（听感/嘴形后半段都不一样）

**除此之外，任何音素都「不需要新做图」，只做 ID 映射。**

## 3. 不需要单独做素材的音素（归并表）

下列音**没有自己的专用图**，服务端请映射到右侧 ID。

### 3.1 声母（多数不单做）

| 声母 | 是否单独做图 | 映射 ID | 说明 |
|:---|:---|:---:|:---|
| **b p m** | 共用 1 张 | **1** | 三者嘴形几乎相同，不拆 b/p/m |
| **f** | 有专用 | **2** | 唯一唇齿 |
| **z c s** | 共用 1 张 | **3** | 不拆成三张 |
| **zh ch sh r** | **不单做** | **3** | 本期并进齿缝；外观差异小 |
| **j q x** | **不单做** | **6** | 并进 i（扁拉） |
| **d t n l** | **不单做** | **3**（或跳过并进韵母） | 舌位音，嘴几乎看不出；**n 不单做** |
| **g k h** | **不单做** | **5**（或跳过并进韵母） | 嘴形弱，一带而过 |
| **y** | **不单做** | **6** | 同 i |
| **w** | **不单做** | **8** | 同 u |
| **零声母** | **不单做** | 跟韵母 | 无声母可直接出韵母 ID |

### 3.2 韵母（按类归并，不按每个韵母做图）

| 韵母 | 是否单独做图 | 映射 ID | 说明 |
|:---|:---|:---:|:---|
| **a** | 类共用 | **4** | 类代表 |
| **ai ao an ang** | **不单做** | **4** | 并进 a；精细可选滑音见 §5 |
| **o uo** | 类共用 | **7** | o 为代表；uo 可不拆 |
| **e ê ei en eng** | 类共用 | **5** | 不拆 ei/en/eng 各一张 |
| **i** | 类共用 | **6** | 类代表 |
| **ia ian iang ie in ing** | **不单做** | **6** | 并进 i |
| **u** | 类共用 | **8** | 类代表 |
| **ua uai uan uang ui un ou ong** | **不单做** | **8** | 本期并进 u |
| **ü** | 类代表 | **9** | 纯撮口（女、绿） |
| **üe** | **不单做** | **9 → 5** | 滑音：先 ü 后 e；**勿整段=9** |
| **üan** | **不单做** | **9 → 4** | 滑音：先 ü 后 a |
| **ün** | **不单做** | **9** | 撮口为主 + 鼻音，嘴形仍近 ü |
| **er** | **单独做** | **10** | 与 ü/üe 都不同 |

> `üe` 不等于 `ü`：要出时间轴滑音。`üe` **不必新画一张图**，用已有 ID9+ID5 即可。

### 3.3 其它

| 类型 | 是否单独做图 | 映射 ID |
|:---|:---|:---:|
| 静音 / 停顿 / 句间 | 有 | **0** |
| 声调（阴平/阳平/上/去） | **不做口型** | 不影响 ID |
| 轻声 | **不做口型** | 跟音节音素走 |

## 4. 完整映射速查（服务端可直接实现）

### 4.1 声母 → viseme_id

```text
b,p,m          -> 1
f              -> 2
z,c,s          -> 3
zh,ch,sh,r     -> 3
d,t,n,l        -> 3      # 也可省略声母段，直接进韵母
g,k,h          -> 5      # 也可省略声母段，直接进韵母
j,q,x          -> 6
y              -> 6
w              -> 8
(null initial) -> (skip)
```

### 4.2 韵母 → viseme_id

```text
a,ai,ao,an,ang           -> 4
o,uo                     -> 7
e,ê,ei,en,eng            -> 5
i,ia,ian,iang,ie,in,ing  -> 6
u,ua,uai,uan,uang,ui,un  -> 8
ou,ong                   -> 8
ü,v                      -> 9        # 纯撮口；v=ü 的另一种写法
üe                       -> 9 -> 5   # 必须按滑音，禁止整段只写 9
üan                      -> 9 -> 4   # 滑音
ün                       -> 9        # 近纯 ü
er                       -> 10       # 儿化，禁止映射到 9
silence / pause          -> 0
```

## 5. 滑音（üe 等：推荐默认做；仍不新做图）

下列韵母用**已有 ID 的时间序列**，不必新素材：

| 韵母 | 推荐序列 | 简单降级（观感较差） |
|:---|:---|:---|
| **üe** | **9 → 5**（约前 40% 用 9，后 60% 用 5） | 仅用 9（不推荐） |
| **üan** | **9 → 4** | 仅用 9（不推荐） |
| ai | 4 → 6 | 只用 4 |
| ao | 4 → 7 | 只用 4 |
| uo | 8 → 7 | 只用 7 |
| ia / ie 等 | 6 为主，韵腹再切 4/5 | 只用 6 |
| ün | 9 | 只用 9 |

## 7. 给服务端的输出约定（建议）

与 TTS 音频时间轴对齐，例如：

```json
{
  "text": "你在干嘛",
  "visemes": [
    {"id": 3, "t0_ms": 0, "t1_ms": 50},
    {"id": 6, "t0_ms": 40, "t1_ms": 180},
    {"id": 3, "t0_ms": 170, "t1_ms": 230},
    {"id": 4, "t0_ms": 210, "t1_ms": 320},
    {"id": 6, "t0_ms": 300, "t1_ms": 380},
    {"id": 5, "t0_ms": 370, "t1_ms": 420},
    {"id": 4, "t0_ms": 400, "t1_ms": 560},
    {"id": 1, "t0_ms": 540, "t1_ms": 620},
    {"id": 4, "t0_ms": 600, "t1_ms": 900},
    {"id": 0, "t0_ms": 880, "t1_ms": 1000}
  ]
}
```

约束：

- `id` 只能是 **0～10**（本期）  
- **er 必须为 10，禁止写 9**  
- **üe 推荐输出两段 9→5，禁止整段只写 9**  
- 允许相邻段时间重叠（供端侧做提前量/交叉淡入）  
- 若 TTS 只给 phoneme 字符串，服务端按 §4 / §5 查表转成 id

## 8. 一句话清单：到底哪些「不用做图」

**不用单独做素材的（归并进 0～10）：**

- 声母：d t n l、g k h、j q x、zh ch sh r、y、w，以及 b/p/m、z/c/s 各自内部不拆开  
- 韵母：ai ao an ang、ia ian iang ie in ing、ua uai uan uang ui un ou ong、**üe（用 9→5，不新做图）**、**üan（用 9→4）**、ün（→9）、uo、ei en eng  
- 声调、轻声  

**必须做素材的：11 个 Viseme 文件（ü=9、er=10 分开；üe 不另做图）。**
